# Stocktrade-with-news

StockTrade with News is an automated, AI-driven algorithmic trading engine designed to turn financial news into actionable trading strategies in real time.
By integrating direct news API feeds, Google Gemini’s multi-step reasoning models, and Alpaca’s automated execution platform, StockTrade with News bridge the gap between financial headlines and market execution.
